# 字幕翻译质量评估（TQA）框架

> **适用范围**：法语电视剧字幕翻译质量评估  
> **翻译链路**：法语原片 → 英文字幕 → 简体中文字幕  
> **版本**：v1.0  
> **首次应用**：*Un Village Français*（法兰西小镇）S01E03 / S01E06

---

## 一、评估维度体系

本框架定义了 **9 个核心评估维度**，涵盖从词义准确到语体风格的完整翻译质量光谱。各维度之间可以叠加（一条字幕可能同时触发多个维度的评估需求）。

### 1. 历史文化术语 `[历史文化术语]`

**定义**：涉及特定历史时期（如二战德占区）的专有概念、制度名称、军事术语、地名、行政体系等，需要译者具备背景知识才能准确翻译。

**关注点**：

- 德语军事术语的中文转写与含义准确性（Kommandant, Feldwebel, Stalag, Ausweis, Kommandantur 等）
- 法国行政体系称谓的对等翻译（Sous-Préfet → 副省长, Commissaire → 警长, Commune → 市镇）
- 历史事件与制度的准确传达（Armistice Convention → 停战协定, Demarcation Line → 分界线, Montoire 会面, SFIO 等）
- 占领区特有制度的解释性翻译（Interzonal Postcard → 跨区明信片, Secours National → 国民救济会）
- **术语/事实性错误**也归入此维度（如将 quince 误译为"木瓜"而非"榅桲"，属于词义准确性问题）

**典型测试样例**：Stalag → 战俘营 ✓ / 集中营 ✗；Kreiskommandant → 区司令官 ✓


### 2. 政治意识形态术语 `[政治意识形态]`

**定义**：涉及特定政治立场、意识形态话语体系、党派用语的翻译。本剧涉及维希政权官方话语、共产党组织术语、抵抗运动语言三套平行话语系统。

**关注点**：

- 维希政权话语的准确传达（National Revolution → 国民革命, Collaboration → 合作/合作政策, L'État Français → 法兰西国家）
- 共产党组织术语（Comrade → 同志, Party Line → 党的路线, Party Order → 党的命令, cell → 支部/小组）
- 抵抗运动话语（saboteur → 破坏者, provocation → 挑衅行动）
- 三套话语之间的区分度——同一事件在不同阵营口中的表述应有差异


### 3. 长句/复杂句 `[长句/复杂句]`

**定义**：原文信息密度高、包含多层逻辑关系、多从句嵌套或多信息单元压缩的字幕条目。

**关注点**：

- 在字幕时长限制内是否完整传达了核心语义
- 逻辑关系（因果、让步、条件）是否清晰
- 多角色/多身份信息是否准确对应
- 是否存在关键信息遗漏


### 4. 习语/俗语/口语化表达 `[习语/口语]`

**定义**：英文字幕中的习语、俚语、粗俗表达、比喻性表达到中文的自然转换。

**关注点**：

- 习语是否找到了功能对等的中文表达（而非字面翻译）
- 粗俗程度是否与原文匹配（如"crap all over us"不应被雅化为"给我们添麻烦"，也不应过度粗俗化）
- 比喻性表达是否在中文中自然可懂（如"the noose is tightening" → "绞索在收紧"）
- 韵脚/修辞效果是否有所保留或补偿（如"steal/squeal"的押韵教训）


### 5. 上下文依赖 `[上下文依赖]`

**定义**：单条字幕的翻译准确性依赖于对前后剧情、角色关系、历史背景的理解。脱离上下文可能导致误译或歧义。

**关注点**：

- 代词指代是否明确（he/she/it/they 在中文中是否需要显化）
- 讽刺、反话、弦外之音是否传达（如"I haven't had the opportunity to congratulate you" 的讽刺性祝贺）
- 隐含的歧视/偏见信号（如询问犹太身份、暗指犹太哲学家斯宾诺莎）
- 跨场景的因果链接（如绳子线索跨越多个场景）
- 角色知识差——观众知道但角色不知道（或反之）的信息是否正确处理


### 6. 正式/官方语体 `[正式语体]`

**定义**：涉及官方声明、法律条文、行政命令、政治演讲等正式场合的语体把控。

**关注点**：

- 官方演讲的庄重感是否保留
- 法律/行政用语的精准度
- 正式语体与角色日常口语之间的语域切换是否自然
- 同一角色在公开场合与私下的语体差异是否在译文中有所体现


### 7. 非母语角色对白 `[非母语口语]`

**定义**：角色以非母语说话，原文英字幕已刻意保留语法错误、词汇简化等特征，中文翻译需要处理的三层转译问题。

**评判标准**：采用**"可理解前提下适度保留外国人语感"**策略。具体而言：

- **保留要素**：短句化、省略连接词、偶尔缺少主语——这些在中文中也是自然的简化方式
- **不强制保留**：英文特有的语法错误（如 "It not fair"），因其在中文中无对等表现形式
- **核心判据**：中文观众能否从译文感知到"这个角色不是母语使用者"且不影响理解

**典型样例**：  
- EN: "I sleep. Not hear noise." → CHS: "我在睡觉 没听到声音" ✓（简短、无赘述，保留简化感）
- EN: "Not buy. Is gift." → CHS: "不是买的 是送的" ✓（语法正确但保持极简风格）
- EN: "It not fair! Not thief." → CHS: "不公平！我不是小偷" ✓（情急之下的简短呼喊）


### 8. 情感/戏剧张力 `[情感张力]`

**定义**：高情绪强度场景中，译文是否保留了原文的情感力度和戏剧节奏。

**关注点**：

- 情绪强度是否匹配（绝望、愤怒、悲痛、讽刺等）
- 语气词和叹词的处理
- 简短有力的台词是否保持了冲击力
- 角色情感转折（如突然的崩溃、决绝的告别）的节奏感


### 9. 讽刺/言外之意 `[讽刺]`

**定义**：台词字面意思与实际意图存在偏差的情况，包括讽刺、反话、冷幽默、含沙射影。

**关注点**：

- 讽刺的锋芒是否保留（不被中和为平淡陈述）
- 反话是否在译文中可感知
- 暗讽/影射是否传达（如用斯宾诺莎暗指犹太身份）
- 黑色幽默的效果是否在中文中成立

## 二、抽样策略

### 2.1 抽样比例

以每集字幕全量的 **10%±1%** 为目标。具体数量根据全集条目数浮动：

| 全集条目数 | 抽样目标 | 实际容差 |
|-----------|---------|---------|
| 500-600   | 50-60   | ±5      |
| 600-700   | 60-70   | ±5      |
| 700-800   | 70-80   | ±5      |

### 2.2 抽样方式：定向抽样（非随机）

不采用随机抽样。每条样例均经过人工/AI 筛选，确保承载明确的翻译难点测试意图。抽样偏向于：

- **高信息密度**条目（长句、多角色信息压缩）
- **高误译风险**条目（习语、文化专有项、讽刺）
- **高上下文依赖**条目（脱离语境容易误解）
- **高情感强度**条目（语气/情绪把控）
- **语域切换节点**（同一角色在正式/非正式场合间的转换）

明确排除以下类型：

- 纯礼貌用语（"Bonjour" / "Merci"）
- 无语义负载的短句（"Yes." / "No." / "Good."）
- 纯动作指示（"Come." / "Stop."）

### 2.3 维度覆盖均衡性

每集抽样应确保 9 个维度的合理覆盖。以下为参考分布比例（允许因剧情特征浮动）：

| 维度             | 建议占比 | 说明 |
|-----------------|---------|------|
| 上下文依赖        | 25-35%  | 占比最高，因为字幕翻译中上下文误解是最常见的质量问题 |
| 长句/复杂句       | 15-25%  | 信息密度高的条目更能暴露遗漏和误解 |
| 习语/口语         | 10-18%  | 口语化表达的自然度直接影响观众体验 |
| 历史文化术语       | 10-18%  | 本剧特有的高密度历史专有项 |
| 政治意识形态       | 8-15%   | 剧情相关时比例上升 |
| 情感张力          | 8-15%   | 关键戏剧场景 |
| 讽刺/言外之意     | 5-12%   | 精选高辨识度案例 |
| 正式语体          | 5-10%   | 官方演讲、法律场景 |
| 非母语口语        | 视角色出场  | 仅在该类角色出场时纳入 |

### 2.4 多维度叠加标注

一条字幕可同时标注多个维度，用 `+` 连接。例如：

```
[长句/复杂句+上下文依赖] 政治博弈的复杂推理——为德国人办案的道德困境
```

这表示该条目同时在"信息完整度"和"语境理解"两个层面构成翻译难点。

## 三、输出格式规范

### 3.1 测试样例文件格式

输出为标准 `.srt` 字幕文件，每条样例包含：

```
[序号]
[时间码]
[维度标签] 测试说明
[中文译文]
[英文原文]
```

示例：

```
14
00:05:31,560 --> 00:05:36,080
[长句/复杂句+上下文依赖] 政治博弈的复杂推理——为德国人办案的道德困境
市长先生 如果我们为了从
德国人那换好处而办案 就完了
Monsieur le Maire, if we start to do police work
to obtain something from the Boches, we're done for.
```

### 3.2 文件命名规范

```
{剧名}_{季集号}_翻译测试样例.srt
```

示例：`A_French_Village_S01E03_翻译测试样例.srt`

## 四、评估工作流

### 4.1 标准流程

1. **解析源文件**：读取英文 `.srt` 和中文 `.srt`，确认条目数一致、序号对齐
2. **全量扫描**：AI 通读全部英文字幕，识别剧情线索、角色关系、文化背景
3. **定向选取**：按 9 个维度体系，从高难度候选池中筛选目标比例的样例
4. **交叉标注**：为每条样例标注主维度+辅维度+具体测试说明
5. **格式输出**：生成标准 SRT 格式的双语测试样例文件
6. **覆盖校验**：检查维度分布是否均衡，必要时补充覆盖不足的维度

### 4.2 质量自查清单

- [ ] 样例数量在全量 10%±1% 范围内
- [ ] 9 个维度均有覆盖（非母语口语视角色出场情况）
- [ ] 无重复条目
- [ ] 英文与中文字幕正确配对
- [ ] 每条样例均有明确的测试说明（非泛泛标注）
- [ ] 时间码与原始文件一致
